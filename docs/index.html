About UnNiYam Shop

An online fashion store built for the MDT312 course. Customers browse and buy, sellers manage their own products, and admins manage users and approve new sellers.

Original stack

HTMLCSSVanilla JSNode.jsExpressMySQLMulterCookie sessions

Features

  • Product catalogue with category filter, search, flash sale and multi-image gallery
  • Register / login with profile photo, edit profile, role-based menus
  • Cart with stock limits, collectable vouchers and discount codes
  • Checkout with saved addresses and PromptPay, COD or card options
  • Order history and notifications
  • Seller dashboard: add, edit and delete products with up to 5 images
  • Admin dashboard: change roles, suspend users, approve seller requests

About this demo

The real project runs on an Express REST API with a MySQL database. For this hosted version the API calls are replaced with an in-browser data layer, so it works without a server. Payments are simulated. Use Reset demo at the top to restore the starting data.
